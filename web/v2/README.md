# Terrax V2 · 肉眼观看尺度

在原动态天空基础上单独建立的观察版本。V2 使用独立入口与设置。星表、图片与 reference 保留；2026-09-14 按用户要求，两版的平面图和沉浸图均采用默认 6 倍天体显示增强。

打开 [沉浸天球](./star_map.html) 或 [平面星图](./sky_atlas.html)。本机已在 8000 端口预览时可直接访问：

- http://127.0.0.1:8000/web/v2/star_map.html
- http://127.0.0.1:8000/web/v2/sky_atlas.html

侧栏“天体显示大小”可在 1–8 倍间调整，背景星、日月和行星一起放大；默认 6 倍主要改善复位后的整图识读。真实角径、星等、轨道和时刻不变。

如需校准后的真实角尺度，先按实际设备填写屏幕尺寸和观看距离，再点击“肉眼尺度 1×”，将观看倍率和天体增强同时恢复为 1。默认 27 英寸、60 厘米只是示例。用实物尺对齐页面中的 5 厘米标尺，可以校正操作系统缩放和网页缩放造成的尺寸误差。

“光扩散：开 / 关”就在画面底部，点击后可以在同一时刻和视角比较。默认开启轻微光扩散。3× 以上的增强星点与 V1 平面图使用相同的清晰符号，随观看倍率和星等改变大小，不把抗锯齿像素乘成大光斑；1× 保留原有光学点像，1–3× 连续过渡。增强模式的光扩散继续作用于日月。侧栏还可以调整显示亮度、扩散宽度与晴空消光；这些调整不会扩大月面的不透明轮廓。亮面先按圆形像素覆盖处理，再做显示层的轻微扩散；夜空采用暗蓝显示基调。扩散效果是屏幕近似，并非太阳或人眼绝对亮度的复刻。

平面页默认与 V1 一致的方位等距双半球图，保留深色底、清晰边框、横竖自适应布局、拖动平移和鼠标锚点缩放。日月及行星盘面在两版平面图上均使用保留局部投影面积的圆形符号，避免离开天极后被拉成椭圆；盈亏保留原相位角，亮面朝向投影后的光源。暗面遮挡、原生星点遮挡与辅助线裁剪共用圆形轮廓。地图星点复用 V1 的像素采样核、星等大小与亮度规则，地图与局部视图共用天体显示倍率。点击天体仍在平面图中定位；“双半球复位”恢复整图，保留所选天体大小。点击“肉眼尺度 1×”可进入校准后的局部立体视图。总览是地图缩略图，不代表 1∶1 肉眼大小。[离轴双月修复及验证](../../data/atlas_body_validation_20260915/summary.md)记录了此前只有 Sol 采用圆形显示的遗漏。

局部视图与沉浸页可拖动转头，滚轮和加减按钮统一缩放全部天体。最终星点按屏幕像素绘制；大窗口仅对天光与日月图像采用受限的中间分辨率，随后在原生分辨率上合成星点，避免整张星空被放大插值。时间、地点、初值、局部观看倍率与光感设置在两页之间共享；平面图的平移和地图缩放独立。V2 不改写 V1 的当前设置。

最新数据集有 9356 颗点源。新数据加入同龄星团和云气；两页也共用固定黄道的 15 个天区，每区 24°，可独立开关。地表模式会依据地平线、太阳和月光背景筛选，因此同一时刻肉眼达标数量会少于全天星表。关闭“大气与昼夜”可单独比较天体；选择“全天星图”可查看地平线下的另一半天空。

星云和星团的弥散光按独立的连续球面亮度剖面绘制，保持实际角范围，不接受 6× 的点源/日月符号增强；随观看视野同比缩放，放大时不再放大固定光图的方形像素。两版先按总光量筛出 160 个必要候选，不能把它们都称为肉眼可见目标。背景星继续使用独立的原生像素点像。详见[银河环境与生成科学说明](../../data/galactic_sky_science.md)。进动、章动候选尚未接入页面运动。

两版平面图左上角同时显示地图缩放、天体显示倍率和每度像素数。比较星点大小时，需对齐每度像素数与天体显示倍率；仅缩放数字接近，并不足以保证角尺度相同。辅助网格、天区、轨迹及画面文字已统一调淡，星点、月面亮度和不透明遮挡不受影响。

随后按蓝色银道线、绿色赤道线的观感重新统一辅助线强度，网格不再被多次调淡。V2 网格与天区、轨迹共用清晰的画面辅助层，不经过光扩散，日月盘面仍遮住这些线。气体云的理想电离前沿在显示层柔化，物理亮度缓冲保持原剖面；目前依然没有生成丝状、壳层等非球形云结构。[本轮核验](../../data/haze_validation_20260915/summary.md)包含 V1 投影反方向覆盖问题的复现与修正。

[计算依据、科学来源与验证范围](./data/validation.md)解释了屏幕角尺度、光量、真实遮挡和光扩散的关系。该版本保留固定椭圆轨道近似，并未进行具体观察者的人眼实验标定。

需要支持 WebGL 2 浮点绘图的浏览器。Three.js 0.160.0 从公开 CDN 加载，首次运行需要联网。运行检查：

```sh
node --test web/v2/tests/eye_model.test.mjs tests/test_display_scale.mjs
```

在已启动的本地预览中打开 [实际图形与两页交互验收](./tests/render_checks.html)。它使用独立的内存设置，避免改动用户的播放时刻。
