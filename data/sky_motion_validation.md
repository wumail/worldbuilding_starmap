## 时间与运动

地球年采用 365.25 个 86400 秒日。取最慢行星 Neptune-Sol 的周期为演示总长：

```
140.49 地球年 = 51313.9725 地球日
                ≈ 92.36291532 Terrax 年
                ≈ 47366.743846 个 26 小时自转日
```

这不是所有天体共同复位的周期。末尾自动暂停，“从头播放”是显式跳回第 0 日。

26 小时解释为恒星自转周期。平均太阳日由 `1/P太阳日 = 1/P自转 − 1/P公转` 得到 **26.050797826 小时**，因此界面没有把“26h 自转日”标成真正的平均太阳日。

轨道模块为 [`solar_system.mjs`](../solar_system.mjs)：

1. 由 `M(t) = M₀ + 2πt/P` 得到平近点角，以 Newton 法求 `E − e sin E = M`。
2. 轨道平面位置为 `[a(cos E − e), a sqrt(1−e²) sin E, 0]`，执行 `Rz(Ω) Rx(i) Rz(ω)`。按设定周期推进，并未把匀速圆周角当成偏心椭圆上的真实角位置。
3. 行星位置由黄道坐标旋转 25° 到母星赤道坐标；卫星相对轨道已经处于赤道参考面，加上 Terrax 的日心位置即可。
4. 每个天体都减去观察者的日心位置，再归一化。外行星逆行自然来自这一步相对运动，无需添加逆行动画。
5. 地表观察者再加自转后的星球半径与高度位移。赤道方向通过同一个正交矩阵转为地平坐标：`+X 北、+Y 西、+Z 天顶`。三维相机始终在观察坐标原点，拖动只转头，滚轮只改变视场。

背景恒星使用原始距离和固定空间方向，包含 Terrax 公转与地表位移造成的视差；视星等沿用星表，没有随 AU 级位移做微小通量修正。没有恒星速度数据，因而未编造恒星自行。在质心方式下，远方恒星几乎不动是合理结果；地表方式中的明显运动主要来自母星自转。

轨迹采用 257 个时刻采样。“26 小时”轨迹显示各时刻的地平位置；“一个 Terrax 年”轨迹扣除日周转动，与当前恒星背景对齐。年轨迹的惯性方向可缓存，但每帧仍随当前观察矩阵转动。轨迹窗口限定在模拟时间范围内，靠近起终点时向范围内部平移。它是位置辅助线，不能据此认定线上的每个位置当时都可见。

两页保存一个共同的时间锚点，以实际经过的时间乘播放速度求模拟时刻，不各自逐帧累加。时间、播放与速度作为一组更新；地点和图层等字段分别合并，并处理旧事件与同时写入。暂停后两页读取完全相同的模拟日数。高速播放会跳过短暂天象，界面提供提示。

## 星等、相位与画面

反射光天体使用原文指定的 Lambert 球：

```
Φ(α) = [sin α + (π − α) cos α] / π
m = −26.493 + 5 log10(r / 1.34 AU)
              − 2.5 log10[Ag (R / Δ)² Φ(α)]
照明面积比例 = (1 + cos α) / 2
角直径 = 2 asin(R / Δ)
```

其中 `r` 为天体至 Sol 的距离，`Δ` 为天体至观察者的距离，`α` 为天体处的太阳—观察者夹角；`R`、`Δ` 使用相同长度单位。照明面积与通量相函数分开计算。盘面亮面朝向真实太阳方向；面板另给明确标注的放大相位示意。

标准满相 Luna / Echo 分别约 −12.75 / −9.90 等。Neptune-Sol 标准冲日约 +6.91 等，超过 6.5 等阈值：可显示空心辅助位置圈，但不绘制可见星点来伪造亮度。

逐体复核采用默认展示初值、Terrax 质心、每 5 地球日采样并补总时长终点，共 10,264 个时刻。以下是采样范围，不是所有可编辑初值的精确极值；星等未扣遮挡或月食。

### 当前绘制口径（角尺度与投影修订）

**视星等适用于月亮，但总光量不能单独决定盘面大小。** 固定半径、反照率、太阳照明和相位后，可以用光度反查距离及角径；盈亏变暗则不会使暗半球消失。地球满月约 −12.7 等描述总光量，约半度的视直径描述天空中所占的大小，需要分别给出。现在实体角直径始终为 `2 asin(R/Δ)`，不再用星等放大整个不透明月面。距离变化会同时改变角径与视星等；两者仍由同一套观测几何正向计算。

| 对象 | 决定几何尺寸的量 | 显示亮度和增强 |
|---|---|---|
| Sol | 实际角直径，约 26′ | 日面自发光；可关闭的柔光限于日面角半径的 2.2 倍 |
| Luna / Echo | 各自实际角直径，约 31.6′ / 6.9′ | 球面受光方向决定盈亏；明暗增强只调亮面颜色，增益最多 4，不改轮廓或遮挡 |
| 六颗行星 | 实际角直径，约数角秒至数十角秒 | 肉眼未分辨光点共用背景星的显示点像，可关闭光点查看盘面 |
| 背景恒星 | 显示点像的角尺度；不把它称为恒星实体直径 | 按星等连续改变点像大小和强度，压缩显示动态范围 |

两页在**投影中心、相同每弧度像素数和 DPR** 下使用同一尺度。令 `F₀ = 128/tan(30°) = 221.7025 CSS px/rad`：

- 平面方位等距图的中心角尺度 `F = 半球半径 / (π/2)`。
- 普通透视的中心角尺度 `F = 窗口高度 / [2 tan(垂直视场/2)]`。
- 立体投影的中心角尺度 `F = 窗口高度 / [4 tan(垂直视场/4)]`。
- 三者的星点半径统一为 `pointRadius(m) × F/F₀`，最后再乘设备像素倍率。旧版平面页把半球半径 200 px 当成相同基准，实际使星点比沉浸页大 **74.12%**；现已纠正。

星点曲线为 `min(0.17, 0.023 × 10^(0.09 × (6.5 − m)))`，峰值权重沿用 `min(1, 0.5 × 10^(0.14 × (6.5 − m)))`。0 等星的显示点像直径约 **2.75′**，6.5 等约 **0.713′**，最亮点像上限约 **5.27′**；这些是显示参数，不是实测人眼 PSF。当前星表的星等区间内半径曲线没有平台。行星光点使用相同曲线、同一纹理和同一倍率，Echo 的完整盘面不会再被几十角分大小的普通光点压倒。

低分辨率下不能靠放大实体补偿漏采样：两页均对小盘面的像素覆盖积分，月面的明暗写入 RGB，盘内不透明。盘缘及不足一像素的盘面允许按实际覆盖面积参与抗锯齿。星点共用 5×5 覆盖样本组成的纹理；亚像素的可辨识度增强在半径 0.5–2 个设备像素之间平滑退出，2 px 接口衔接完整点像的积分，避免采样分支突然改变亮度。大点像也先积分像素面积再插值平移，确保接口两侧的滤波一致；半径量化步长为 1/128 个设备像素。该对比度处理不能用作通量测量。

全天图将整个天空压进窗口：半球半径 200 CSS px 时，Luna 的径向直径约 1.17 px，Echo 约 0.26 px；有限像素不能同时呈现其全部细节。两页新增“放大观察”，同步放大该区域内的所有天体。平面最大缩放为 128 倍，沉浸最小垂直视场为 1°；没有单独给月亮施加几何放大。

### 投影、可见性与遮挡

- 默认全天从母星质心观察，保留 9327 颗背景星；地表模式才应用地平筛选和可选的近似昼夜阈值。晴暗夜阈值为 6.5 等，晨昏阈值为示意。数量表示通过筛选的星表项，不保证缩略图中能逐一数清每个像素光点。
- 沉浸页默认立体投影，并保留“透视投影”选项。网格、参考文字、轨迹、天体盘面、日晕、恒星和行星光点均采用对应投影；标签、拾取和拖动共用正反投影。相机仍在观察者原点。
- 立体投影将球面圆映为圆或直线，保留局部角度，但离轴比例仍会变化。普通透视下，离轴天球小圆成为椭圆是正常几何。把球壳换为天空盒仍用透视成像，不能消除该椭圆。平面方位等距图在边缘有切向拉伸，扩展盘面随地图变形；星点是保持圆形的显示符号。因此跨页比较应匹配局部角尺度，不能直接比较任意两个默认窗口的像素直径。
- 真实实体按距离从远到近覆盖。月面亮、暗两部分都遮挡背景，增强开关不改变完整轮廓。完全被前景实体包住的后方实体先按球面几何剔除，避免亚像素图层独立混合时在全食中留下太阳亮点。部分重叠仍是分层栅格近似，边界受有限采样和抗锯齿影响；不将它用于精密食象测量。
- 日晕在太阳所在的距离层绘制，并按真实日面剩余可见光衰减；前景月面随后覆盖。地表模式对盘面及光点执行相应投影的地平裁剪。地平下的名称、空心辅助标记可以在开启辅助图层时保留，不表示该天体肉眼可见。
- 相位预览与两月角径对照仍是明确标注的辅助图。盘面颜色、亮度压缩、亚像素对比度增强和太阳柔光均未作人眼或相机曝光标定，显示像素总和不等于实际天体通量。星等数值采用上文的物理公式，显示明暗采用 Lambert 球及说明中的增强。
