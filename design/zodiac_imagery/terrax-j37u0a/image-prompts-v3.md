# Terrax 星座意象：第三版生图提示词——单色版画主体

本版沿用第二版的意象选择，按用户提供的参考图改为单色仿古版画风格。最终每张只交付一个完整意象主体，不包含文字、星点、连线或装饰符号。默认采用透明背景，便于作为独立插画图层。具体形象仍是候选，尚未生成插画。

优先试画 Z15，判断“前倾、伸手、屈膝”的组合能否表达侍奉。人物身份可暂称侍者；仆从、献礼者、侍祭等社会身份还不能仅凭星位确定。

联想可以跨得很远，但优先从熟悉的姿态、动物和器物中取得支撑。形象本身先能成立，故事再赋予含义；也允许故事启发姿态选择。双首蛇的奇异之处集中在两个头，其余仍沿用熟悉的蛇体。其他星座无需为了显得古老而统一加入巨兽、神职或宇宙使命。

## 可复制的通用风格提示词

将本段与下方选定的主题段一起交给生图模型。

```text
画一幅单独的星座意象插图。参考图 1 只用于学习银灰色主体的版画风格，参考图 2 只用于安排姿态与关键部位的位置。具体主体以本次主题描述为准，不照搬参考图 1 的海羊。

风格是古典星图中的单色仿古版画插图。用淡银灰一色绘制；外轮廓明确、有粗细变化与轻微手刻的不规则感，内部以顺着形体的短排线、少量点刻和成组留白表现肌理与体积。头、手足和衣褶应有形，不要只有一条细线轮廓，也不要画成大片实心剪影。细节有疏有密，缩小观看仍能读出完整姿态。

保持平面的印刷插画观感，不使用彩色淡彩、写实厚涂、3D 体积光、金属反光、光晕、投影或渐变塑形。刻印质感集中在主体笔触内部，不生成满画幅的纸纹、污渍或噪点。

整张只有一个完整主体，以及该主体必要的持物。保持构图参考的朝向、比例与位置关系；允许补足轮廓和肢体，不把参考折线机械地画成人体骨架。主体完整入画，沿用参考图的留白，不重新旋转、镜像或挪动构图。

最终图片不包含任何文字、字母、数字、品牌、星座符号、星点、星座连线、几何标记、边框或装饰花纹；不包含背景星空、地面、风景或其他角色。参考星图的线与标记只作为定位依据，交付时全部隐藏。

优先输出 1024 × 1024、真正透明背景的 PNG，保留主体线条之间的透明留白。不要把棋盘格画进图片。若工具不能直接生成透明背景，请用纯深蓝无纹理底并明确说明，以便后处理，不要宣称已透明。最终交付纯主体图，不叠加星点或连线。
```

## Z15：屈膝奉物的侍者——优先试画

```text
用途：illustration-story，虚构世界 Terrax 的传统星座意象草图。
主题：一个侧身朝左、微微前倾、屈膝向前奉上一只浅盘的侍者。角色衣着朴素，动作专注、平稳，靠身体姿态让人联想到侍奉或献礼。画一个完整的人物，不添加被侍奉的人。

构图参考图中的字母仅供定位，最终不绘制。请围绕以下少量锚点安排人体：
B 附近是头部，面部朝左并略向下，B–C 提示头颈与肩部的衔接。
C 附近是肩，C–D 提示向左前方伸出的手臂，D 附近是托着浅盘的手。肘与手指可自然补画，不要求整条手臂笔直。
C–E–G 提示前倾的上身、长衣和下部屈膝的方向。E 可参与腰部转折，G 附近提示着地的膝或最低处的衣褶。不要把 E–G 整段机械地当成一根过长的大腿骨。
G–F–A 提示向后收的腿、足部与衣摆。允许用衣物包住部分肢体，让膝踝结构自然；末段可以进入衣摆轮廓，不强求每颗星都钉在关节上。
另一只手可以托住盘沿，另一条腿可以因侧身与长衣遮挡而只露出局部。这些细节由插画补足，不需要新增星点。

优先表现可理解的人体动作：头在前、手向前奉物、身体略倾、下部屈膝。为保持自然比例，允许原线穿过衣袍内部；不要把全部星链描成僵直的肢骨。
服装为简洁长衣，身份线索主要来自奉物姿态。暂不指定性别、宫廷、宗教或时代，不添加王冠、枷锁、翅膀、神光或夸张的屈辱表情。

使用共同要求中的淡银灰单色版画风格。以有粗细变化的轮廓表现人体，以疏密短排线和留白表现长衣褶皱、手指和浅盘。主体完整，留足手部与盘的空间。
优先交付 1024 × 1024 透明 PNG，只保留侍者和手中浅盘。星位仅用于定位，不显示星点、连线、文字或其他符号；不在最终图片中叠加 Z15-overlay.png。
```

重点检查 B/C 的头肩、D 附近的奉物手与整体屈膝姿态是否相容。下部星链作为腿与衣摆的读法需要草图验证，不能仅凭文字认定人体已经自然。

## Z11：扬帆小舟——替代候选

```text
用途：illustration-story，虚构世界 Terrax 的传统星座意象草图。
主题：一艘张起布帆的古老木舟，侧向展开，船首略高，船尾拖出缆绳。画面以帆、船身和绳索的组合建立识别，不添加人物或神话职能。

附图是位置参考。J–G–E–I–B 的大闭合区域提示鼓起的一面帆，E 是高处帆角，G 参与帆的展开；布帆可超出折线少许，原星线不必全部成为帆的硬边。
J–B–I 参与舟身的下腹线，I–H 提示抬起的船首，J–K–D 提示另一端翘起的船尾。帆脚与船身在投影中可以重叠，不必把同一线段强行分成两个独立物体。
J–C–F–A 提示从尾部垂下再折回的缆绳，A 附近为绳端。允许补画小型系泊物，但不把它当作新增星体。
补齐船舷、桅杆、帆索与木材结构；这些可以没有对应恒星。优先让舟身与布帆的比例、连接关系看起来可用，避免只有一个几何三角形。

使用共同要求中的淡银灰单色版画风格。帆布褶皱、木纹和缆绳以排线疏密区别材质；保持平面印刷观感，主体包括木舟、帆与附属绳索，不绘制水面或港口背景。
优先交付 1024 × 1024 透明 PNG，只保留单艘帆舟。保持参考方向、比例与星位关系，最终不画星点、连线、文字或其他符号，不叠加 Z11-overlay.png。
```

这是对大面、下腹和两端翘起关系的新尝试。重点检验帆与舟身能否自然接合，不能仅因线框较大就宣称它已经像船。

## Z13：持杖的长衣行旅者——替代候选

```text
用途：illustration-story，虚构世界 Terrax 的传统星座意象草图。
主题：一个穿长衣的行旅者，一手抬起持杖，另一侧衣袖自然下垂，身体略有转侧。角色是熟悉的人间人物，以头、抬起的手、衣袖与足端组织姿态，不赋予撑天等超自然职责。

附图是位置参考。D 附近是头，B 附近衔接颈肩，B–E 提示肩部的方向。
E–F 提示抬起的手臂，F 附近是握杖的手；肘部可在两点之间弯曲补画，手杖可以在星线之外自然延伸。
B–E–C–H 提示长衣覆盖的躯干与下摆范围，画出柔软衣褶和人体体积，不把它画成方盒。
H–A 提示另一侧垂下的衣袖，A 可落在袖端。真实手掌可以藏在袖内或在更上方露出，不为了碰到 A 而把手臂拉长。
C–G 提示露在长衣下的一条腿与足端，G 附近是足。另一只脚可因转身、衣摆和前后遮挡而靠近已有腿部补出，不要求增加恒星来标示。
头、持物手、垂袖与足构成四个不同部位，不要求四个外伸端全是四足兽的脚。允许衣物吸收星线的长短差异，人体比例与站立重心应自然。

使用共同要求中的淡银灰单色版画风格。以短排线、成组留白和轻微刻痕表现朴素长衣、手杖与面容；轮廓清楚，衣褶有节奏。角色完整独立，无场景背景。
优先交付 1024 × 1024 透明 PNG，只保留行旅者与手杖。保持参考方向、比例与星位关系，最终不画星点、连线、文字或其他符号，不叠加 Z13-overlay.png。
```

本方案重新分配四个外伸端的角色，尚需检验肩宽、手臂长度与长衣下的重心。若必须严重扭曲人体才能满足这些位置，应放弃该方案；不必为凑足四幅图而定名。

## 验收与交付

最终文件只保留单个意象主体。可以在内部临时叠加对应星图层检查部位，检查后必须移除，不能把带星点、连线或字母的版本当作本次最终图片。确认头、手、尾等关键部位接近参考位置、主体完整、单色线条清楚，且无文字、额外符号或背景元素。

透明输出还需检查 alpha 通道，区分真实透明与画出的棋盘格。如果使用了纯色底的备用方式，需明确标注。姿态与星位相容后，再讨论具体名称和文化故事。
